♦︎ What Makes MtSharpGrain Special?

⏥ Semi-Smooth Node Meshes

Blocks connect with rounded transitions rather than hard cube edges, creating a unique visual style that's smooth and natural.

⚄ JavaScript Modding System

Full-powered modding via GraalJS. Control everything from player location to creating new entities. Perfect for making your own mini-games!

⌘ Console Command System

Use commands like !place and !destroy to interact with the game world. More commands coming soon!

△ Cross-Platform

Play on MacOS, Windows, or Linux. The game is built with Java and OpenGL (LWJGL & JME) for maximum compatibility.

Customizable

As a single developer, I can't make everything. That's why modding is at the heart of MtSharpGrain - anyone can create their own content!

␦ About MtSharpGrain

This project aims to create a futuristic gridded sandbox game using shaders, environment effects, and interconnected nodes. While the current version falls short in some areas, it's constantly improving with new features and refinements.

The game is built 100% in Java using OpenGL (LWJGL) and jMonkeyEngine, providing a solid foundation for performance and extensibility.
